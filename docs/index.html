알아서 하되,
꼭 필요할 때만 물어봅니다

“허용할까요?”를 백 번 누를 필요도, 다 맡겼다가 불안해할 필요도 없습니다. Solar Work는 내가 고른 폴더 안에서만 일하고, 무언가를 지우거나 폴더 밖으로 나가야 할 때만 이유를 붙여 물어봅니다.

  • 내가 고른 폴더 안에서만 일해요. 다른 폴더는 건드리지 못해요
  • 비밀번호·인증서 같은 민감한 파일은 처음부터 못 봐요
  • 물어볼 땐 왜 필요한지를 같이 알려 줘요. 안 된다고 하면 다른 방법을 찾아요
  • 외부 공개 공유는 아무리 맡겨도 항상 내가 직접 확인

첫 화면의 모델 연결 카드에서 로그인하면 Upstage Solar를 무료 사용량 안에서 바로 쓰고, Upstage 콘솔 API 키를 붙여넣으면 한도 없이 씁니다. GPT·Claude·Gemini 같은 다른 AI도 골라 쓸 수 있어요.

💻내 PC에서 일합니다

내가 고른 폴더 안에서 파일을 읽고 씁니다. 대화와 결과물도 내 기기에 저장됩니다.

👀과정이 다 보입니다

어떤 파일을 읽고 무엇을 했는지 실시간으로 보이고, 하는 중에도 방향을 바꿀 수 있습니다.

🔑비밀번호·키는 AI도 못 봐요

연결한 계정의 로그인 정보는 따로 보관되고, AI에게는 원문이 전달되지 않습니다.

🗂️언제든 다시 봅니다

지난 대화와 만든 결과물이 남아 있어, 나중에 이어서 작업하거나 다시 꺼내 쓸 수 있습니다.

📚 문서 작업

워드·엑셀·파워포인트·PDF를 열어 고치고, 합치고, 요약하고, 표로 정리합니다.

📈 데이터 정리

엑셀·CSV를 주면 숫자를 살피고 그래프와 대시보드로 보여 줍니다.

🎬 유튜브 요약

링크 하나로 핵심 요약·챕터·인용을 담은 공유용 페이지를 만들어 줍니다.

🧭 그림으로 설명

조직도, 업무 절차, 일정표 같은 도식을 말로 그려 줍니다.

macOS 설치 안내

dmg를 열어 SolarWork.app을 응용 프로그램 폴더로 드래그하면 바로 실행됩니다. 공증 이전의 오래된 버전(rc.25 이하)이 열리지 않으면:

xattr -dr com.apple.quarantine /Applications/SolarWork.app
Windows 설치 안내

설치 프로그램을 실행합니다. SmartScreen 경고가 뜨면 추가 정보 → 실행을 누르세요. 에이전트가 명령을 실행할 때 Git Bash를 쓰므로 Git for Windows를 먼저 설치해 주세요.

Linux 설치 안내
# Ubuntu / Debian — 의존성까지 자동 설치
sudo apt install ./SolarWork-<버전>-linux-x64.deb

# AppImage
chmod +x SolarWork-<버전>-linux-x64.AppImage
./SolarWork-<버전>-linux-x64.AppImage

AppImage는 libatomic1, libgbm1, ALSA가 필요합니다. FUSE 2가 없으면 --appimage-extract-and-run을 붙여 실행하세요.

업데이트 · 무결성 확인

새 버전이 나오면 앱이 알려 줍니다. 최신 설치 파일을 받아 덮어 설치해도 됩니다. 현재는 프리릴리스(-rc) 단계입니다. 받은 파일은 SHA256SUMS로 확인할 수 있습니다.

shasum -a 256 -c SHA256SUMS --ignore-missing     # macOS
sha256sum -c SHA256SUMS --ignore-missing         # Linux
무결성 확인용 SHA256SUMS · 이전 버전 전체 보기 · Intel Mac은 웹 버전을 써 주세요
