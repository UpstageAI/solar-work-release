01 왜 Solar Work인가

AI에게 일을 맡기기 전에
먼저 풀어야 할 다섯 가지

AI 에이전트는 서류를 읽고, 시스템을 조회하고, 문서를 씁니다. 사람의 일을 대신하는 만큼, 직원에게 요구하는 통제를 에이전트에게도 똑같이 적용할 수 있어야 합니다.

01

데이터가 밖으로 나가지 않아야 한다

고객 서류와 거래 정보가 외부 AI 서비스에 남는 상황

사내 서버에 설치하고, 업무 건마다 작업 공간을 나누고, 데이터를 보존하지 않는 모델만 씁니다.

02

AI가 계정과 키를 몰라야 한다

실행 환경이나 로그에 남은 키가 유출 경로가 되는 상황

키와 토큰은 서버에만 두고, 에이전트에게는 한 번도 보여 주지 않습니다.

03

중요한 실행은 사람이 결정해야 한다

시스템 등록이나 고객 발송을 AI가 혼자 실행하는 상황

도구마다 자동 허용과 사람 확인을 정하고, 승인 전에는 실행하지 않습니다.

04

무엇을 했는지 다시 볼 수 있어야 한다

민원 · 사고 · 감사 때 근거를 설명하지 못하는 상황

지시 · 도구 호출 · 승인 · 결과를 순서대로 저장하고, 같은 순서로 다시 볼 수 있습니다.

05

업무가 늘어도 통제가 유지되어야 한다

부서마다 에이전트와 도구가 제각각 늘어나는 상황

조직 · 프로젝트 권한, 에이전트 버전 관리, 하위 에이전트 권한 상한으로 같은 기준을 지킵니다.

02 업무 시나리오

실제 업무에서는 이렇게 씁니다

금융 업무를 예로, Solar Work가 일을 덜어 주면서도 통제를 지키는 방식을 보여 드립니다.

SCENARIO A지금 사용 가능

여신 심사 서류 검토

심사역은 하루 수십 건의 대출 신청 서류를 확인합니다. 재직 · 소득 증빙, 사업자 서류, HWP 양식을 심사 기준과 하나씩 대조하고 의견서를 씁니다.

심사역은 서류 확인 대신 의견서 검토와 판단에 시간을 씁니다.

  • 고객 서류는 이 건 전용 작업 공간에만 둬 다른 고객 건과 섞이지 않습니다.
  • 심사 기준은 프로젝트 메모리에 두어 모든 심사 건이 같은 기준을 참조합니다.
  • 사내 심사 시스템 등록은 심사역 승인 뒤에만 실행됩니다. 최종 판단은 사람이 합니다.
  • 지시 · 판독 · 작성 · 승인이 감사 기록으로 남아 사후 점검의 근거가 됩니다.
SCENARIO B지금 사용 가능

월말 대량 서류 점검

월말 · 분기말에는 수백 건의 계약서와 체크리스트를 정해진 기한 안에 점검해야 합니다. 표본만 보고 넘어가는 경우가 생깁니다.

표본이 아닌 전수 점검에 가까워지고, 결과는 한 보고서로 모입니다.

  • 서류 묶음을 여러 에이전트에 나눠 맡겨 동시에 점검합니다.
  • 하위 에이전트마다 전용 작업 공간을 써서 결과가 섞이지 않습니다.
  • 하위 에이전트는 총괄 세션보다 넓은 권한을 가질 수 없고, 승인 요청은 총괄 화면에 모입니다.
  • 끝난 하위 에이전트는 자동으로 알리고, 총괄 세션이 결과를 취합합니다.
SCENARIO C지금 사용 가능

사내 시스템 연동 업무

고객 문의를 처리하다 보면 계좌 상태나 처리 이력을 사내 시스템에서 조회해야 합니다. 하지만 AI에게 계정을 그대로 맡기기는 어렵습니다.

에이전트는 사내 시스템을 쓰지만, 계정 정보는 한 번도 보지 않습니다.

  • 계정 토큰은 암호화해 보관하고, 서버에서만 요청에 붙입니다.
  • 위험한 도구는 쓰지 못하도록 막습니다.
  • 모든 도구 호출이 감사 기록으로 남습니다.

04 업무 도구

문서 업무에 필요한 도구를 기본으로

자주 쓰는 도구는 플러그인으로 기본 제공되고, 사내 도구는 같은 방식으로 추가합니다.

문서 판독

HWP · PDF · 스캔 문서를 읽고 표와 본문을 추출합니다.

오피스 문서 작성

Word · PowerPoint · Excel · PDF 형식으로 결과를 만듭니다.

데이터 분석

표 데이터를 탐색하고 통계 · 시각화 · 검증을 합니다.

판정

예/아니오 · 점수 판단을 근거와 함께 내고, 많은 데이터를 한 번에 판정합니다.

이미지 이해

차트 · 캡처 · 스캔 이미지를 설명합니다.

프로젝트 메모리

규정 · 기준 · 이전 결정을 팀의 모든 세션이 함께 참조합니다.

산출물 공유

버전 · 작성 이력과 함께 보관하고, 권한에 맞춰 공유합니다.

사내 도구 연결

사내 시스템과 업무 SaaS를 MCP로 연결합니다. 직원 개인 계정 연결도 지원합니다.
