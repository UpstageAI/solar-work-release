Solar Works 보안·설치 안내 (IT 담당자용)

Solar Works는 사용자 PC에 설치하는 업무용 AI 앱입니다. 사용자가 고른 폴더의 파일을 읽고 쓰며, 답을 만들 때 필요한 내용을 AI 모델로 보냅니다.

2. 네트워크

허용 요청(HTTPS, 443 포트):

주소용도
api.upstage.aiAI 모델 호출
app.solarwork.dev로그인·서비스
  • 위 주소를 HTTPS 검사(SSL 복호화) 예외로 등록하고 Authorization 헤더를 허용해 주세요.
  • 앱은 PC에 설정된 프록시를 쓰지 않고 직접 연결합니다. 프록시로만 인터넷을 허용한다면 직접 연결 예외가 필요합니다.
  • 기관 인증서로 HTTPS를 검사한다면 예외 등록 대신 그 인증서를 PC에 설치하는 방법도 있습니다.
  • 메일·캘린더·드라이브·메신저는 사용자가 연결한 경우에만 해당 서비스로 접속합니다. 웹 탐색 기능은 사용자가 요청한 사이트에 접속합니다.

3. 권한과 승인

  • 작업 폴더 밖에 저장하거나 로그인 정보를 다루는 작업은 승인을 기다립니다. 사용자가 승인 방식을 바꿀 수 있습니다.
  • macOS는 화면 캡처, 다른 앱 자동화 같은 권한을 시스템 창에서 물을 수 있습니다.
  • 예약 작업은 앱이 켜져 있을 때만 실행됩니다.

4. 데이터

  • 사용자 파일은 PC에 있고, 작업에 필요한 내용이 AI 모델로 전송됩니다.
  • '사용 데이터 보내기'는 설정에서 끌 수 있습니다. 앱 안내에 따르면 기능 사용 방식만 보내며 대화 내용·파일 경로·이메일은 포함하지 않습니다.
  • 피드백을 보낼 때 사용자가 고르면 대화 전체도 함께 전송됩니다.
