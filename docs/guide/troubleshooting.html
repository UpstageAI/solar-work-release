문제 해결 가이드

Solar Works를 쓰다가 막힐 때 먼저 확인해 보세요.

설치가 안 돼요

  • macOS: 앱을 응용 프로그램 폴더로 옮긴 뒤 열어 주세요. Apple Silicon(M1 이상), macOS 13 이상이 필요해요.
  • Windows: 브라우저가 다운로드를 막으면 배포자가 Upstage Co., Ltd.인지 확인한 뒤 유지해 주세요. '모든 사용자' 설치는 관리자 권한이 필요해요.
  • 회사 PC라 막히면 IT 담당자에게 보안·설치 안내를 전달해 주세요.

로그인이나 연결이 안 돼요

  1. 로그인 화면에서 네트워크 진단을 눌러 주세요. 어디서 막혔는지 알려드려요.
  2. 휴대폰 핫스팟으로 연결해 보세요. 핫스팟에서 되면 회사·기관 네트워크가 막고 있을 수 있어요.
  3. 컴퓨터의 날짜와 시간이 자동으로 맞춰져 있는지 확인해 주세요.
  4. 진단 결과를 복사해 네트워크 담당자에게 전달해 주세요.

회사 보안 프로그램이나 VPN은 임의로 끄지 말고 담당자에게 먼저 물어봐 주세요.

Windows에서 명령이 실행되지 않아요

Git for Windows를 설치하고 앱을 완전히 껐다 다시 켜 주세요. 창을 닫아도 미니 비서가 남아 있으면 우클릭해 종료해 주세요.

업데이트가 안 돼요

macOS에서 읽기 전용 위치라는 안내가 나오면 최신 앱을 내려받아 응용 프로그램 폴더의 앱과 바꿔 주세요.

무료 사용량을 다 썼어요

앱 설정에서 오늘과 이번 주에 남은 사용량과 다시 채워지는 때를 확인할 수 있어요. 내 Upstage API 키를 연결해 계속 쓸 수도 있어요.

예약한 일이 실행되지 않았어요

예약은 앱이 켜져 있을 때만 실행돼요. 앱이 켜져 있었는지 확인해 주세요.

그래도 안 되나요?

앱의 피드백 버튼이나 고객 지원으로 알려 주세요.

  • 하려던 일과 화면에 나온 문구
  • 네트워크 진단 결과
